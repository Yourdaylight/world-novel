## 6. 已知限制

1. **试读→注册转化**依赖前端 beacon（登录后回跳上报），后端按 (share, user) 去重；
2. **UV 统计**为单实例内存近似（重启清零），PV/阅读数为持久化精确值；
3. **L1 半自动发布**未实现（平台无开放 API，接口以 501 预留）；
4. 评测中的成书为**种子数据**（12 章）：真实 LLM 生成需 API Key，不影响导出/权限链路验证；
5. 正文水印默认关闭（`NOVEL_SHARE_WATERMARK`），核心防线为接口权限 + 限流。
