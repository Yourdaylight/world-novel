  - icon: 📖

  - icon: 🧠
    title: 记忆与技能系统
    details: 情景记忆、语义记忆、信念、创伤、热图与角色技能，让角色行为在长篇中保持连贯。
  - icon: 📦
    title: 单机部署 · 零外部依赖
    details: FastAPI + SQLite + Vue3 单机构架，Qdrant/Neo4j 可选；文档站为纯静态产物，与主应用完全解耦。
