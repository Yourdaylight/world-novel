# 分享与注册阅读

把成书生成一个公开链接发给读者：匿名试读、注册即全文。

## 权限模型

| 级别 | 身份 | 可访问内容 |
|------|------|-----------|
| 匿名 | 未登录 | 封面 / 简介 / 目录 / 试读章节（默认前 3 章，可配置） |
| 注册用户 | 邀请码登录 | **全文** + 书架 + 阅读进度同步 |
| 作者 | 分享创建者 | 全部 + 分享管理（关闭/改试读/看数据） |

::: tip 开源版不设付费墙
「注册即全文」是开源版策略；付费会员（试读上限提升 + 会员全文）
是商业版预留能力，数据模型已留扩展位（`user_quotas.plan_type`）。
:::

## 作者：创建与管理分享

1. 登录工作台，进入「分享管理」页；
2. 点击「新建分享」→ 选择小说、设置试读策略；
3. 获得形如 `https://你的域名/read/9f3k2abXqz` 的公开链接，复制分发。

试读策略（即时生效）：

| 策略 | 说明 | 示例 |
|------|------|------|
| 前 N 章 | 默认，前 N 章免费 | `3` = 前 3 章 |
| 前 N 字 | 按累计字数 | `5000` = 前 5000 字 |
| 按比例 | 全书百分比 | `10` = 前 10% |
| 设为 0 | 不提供试读 | 仅展示元数据 |

「分享管理」还提供：关闭/重开分享、查看 PV / 阅读数 / 注册转化、按日统计。

## 读者：注册即全文

1. 打开分享链接，可免费阅读试读章节；
2. 到达试读边界会弹出注册引导 → 输入邀请码完成注册；
3. 注册后立即解锁全文，阅读进度自动同步；
4. 「加入书架」收藏，下次从「我的书架」继续阅读。

没有邀请码？向站点的管理员索取（开源部署由管理员在后台创建分发）。

## API 参考

```
GET  /api/share/{shareId}             # 分享页元数据（公开）
GET  /api/share/{shareId}/chapters    # 目录 + 每章可读标记（公开）
GET  /api/share/{shareId}/chapter/{n} # 章节正文（匿名=试读边界，注册=全文）
POST /api/share/{shareId}/conversion  # 试读→注册转化上报（注册后）

POST   /api/share                     # 创建分享（作者）
GET    /api/shares                    # 我的分享列表（作者）
PATCH  /api/share/{shareId}           # 改试读/关闭（作者）
DELETE /api/share/{shareId}           # 关闭分享 → 全部公开接口 404（作者）
GET    /api/share/{shareId}/stats     # 阅读数据（作者）

GET /api/bookshelf                    # 书架 + 进度（注册）
PUT /api/bookshelf/{novelId}          # 加入/移出书架（注册）
PUT /api/share/{shareId}/progress     # 更新阅读进度（注册）
```

越权响应约定：匿名请求试读外章节返回
`403 {"detail": {"code": "need_login", "trial_ok": false}}`，**绝不下发正文**。

## 安全设计

- 分享 ID 为 10 位随机短码（去混淆字符），不可枚举；
- 公开分享接口限流：单 IP 每分钟 ≤ 60 次（超限 429）；
- 后端是唯一真相：正文只经权限接口下发，前端不预置任何隐藏内容；
- 关闭分享后所有公开接口立即 404；
- 可选正文水印：`NOVEL_SHARE_WATERMARK=true`（泄露追责用，默认关闭）。
