# 分享与注册阅读

作者把成书生成公开链接分享出去；路人匿名试读，注册后阅读全书。

## 作者：分享管理

工作台进入小说 → 侧边栏「**分享管理**」：

1. 选择**试读策略**并「生成分享链接」；
2. 复制链接（形如 `https://你的域名/read/9f3k2aXy`）发到任意渠道；
3. 随时可调整策略、查看访问数据、一键关闭（**关闭后所有阅读接口立即 404**）。

### 试读策略

| 模式 | 含义 | 值 |
|------|------|----|
| 按章节数（默认） | 匿名可读前 N 章 | N（默认 3，0 = 全锁） |
| 按字数 | 匿名累计可读到指定字数 | 字数 |
| 按比例 | 匿名可读全书百分比 | 0–100 |
| 全本开放 | 不设试读门槛 | — |

元数据（书名/简介/类型）在分享时生成**快照**，后续修改原书不影响已分享页面。

## 读者：试读 → 注册 → 全文

- 打开链接可见：封面占位、简介、目录、试读章节（移动端优先的宋体排版）；
- 点击锁定章节弹出注册引导：
  - **jwt 模式**（开源默认）：直接输入邀请码即完成注册/登录并解锁全书；
  - **casdoor 模式**：跳转企业统一登录；
- 注册读者自动记录**阅读进度**（书架接口已提供，书架页为后续版本 UI）。

> 开源版"注册即会员"：**不设付费、不接支付**，登录即全文。付费会员为商业版预留（`user_quotas.plan_type`）。

## 权限模型

| 内容 | 匿名 | 注册读者 | 作者 |
|------|------|---------|------|
| 元数据 / 目录 | ✅ | ✅ | ✅ |
| 试读章节 | ✅ | ✅ | ✅ |
| 试读边界外章节 | ❌ 403 `need_login` | ✅ | ✅ |
| 创建/修改/关闭分享 | ❌ 401 | ❌ 403 | ✅ |

## 安全设计

- **后端是唯一真相**：正文经 `/api/share/{id}/chapter/{n}` 单章按权限下发，前端永远拿不到隐藏章节；
- **分享 ID 不可枚举**：8 位 URL-safe 随机短码（48 bit 熵），非顺序 ID；
- **限流**：公开阅读接口默认 60 次/分/IP（`NOVEL_SHARE_RATE_PER_MIN` 可调，生产建议叠加 nginx `limit_req`）；
- **无信息泄漏**：公开响应不包含 `novel_id`、作者 ID 或服务器路径；
- **防盗缓解**：服务端限流 + 水印追责位；注：前端禁复制只能防君子，真正防线是"只下发权限内数据"。

## HTTP API

```bash
# 公开
GET /api/share/{id}                 # 元数据（自动 +1 PV）
GET /api/share/{id}/chapters        # 目录（逐章可读标记）
GET /api/share/{id}/chapter/{n}     # 单章正文（越权 403 need_login）

# 作者（需登录）
POST   /api/share                   # 创建分享（同书幂等，返回已存在链接）
GET    /api/shares                  # 我的分享
PATCH  /api/share/{id}              # 改试读策略 / 关闭|开启

# 注册读者（需登录）
GET  /api/bookshelf                 # 书架 + 进度
POST /api/share/{id}/progress       # 上报阅读进度
```
