# 公开分享与注册阅读

作者可把成书生成一个公开链接，匿名读者试读，**注册后阅读全书**。

## 作者：创建与管理

进入工作台「**分享**」页：

1. 选择试读策略，点击「生成公开链接」；
2. 复制链接（形如 `https://你的域名/read/9f3Kp2xQ7b`）发给读者；
3. 可随时**调整试读策略**（即时生效）或**关闭分享**（所有公开接口立即返回 404，原链接重新开启后继续有效）；
4. 查看浏览量与章节阅读数。

### 试读策略

| 模式 | `trial_mode` | `trial_value` |
|------|--------------|---------------|
| 前 N 章（默认） | `first_n_chapters` | 章节数（默认 3） |
| 按字数 | `word_count` | 累计字数 |
| 按比例 | `ratio` | 全书百分比（0–100） |

## 读者：试读到注册

- 打开链接看到封面、简介、目录与正文，移动端优先排版；
- 目录中超出试读范围的章节显示锁标识；
- 点击锁定章节弹出注册引导：
  - **jwt 模式**：输入邀请码即可注册 / 登录，立即解锁全书，阅读进度自动同步到书架；
  - **casdoor 模式**：跳转统一认证中心。

## 安全设计

1. **后端是唯一闸门**：章节正文只经 `/api/share/{id}/chapter/{n}` 按权限下发，前端永远拿不到隐藏章节数据。
2. **越权响应**：匿名请求试读外章节 → `403 {"detail":{"code":"need_login"}}`，响应体不含正文。
3. **分享 ID 不可枚举**：10 位随机码（约 58 bit 熵，去除易混字符）。
4. **关闭即 404**：关闭 / 不存在的分享返回完全相同的 404，不泄露分享是否存在。
5. **限流**：公开分享接口默认每 IP 每分钟 60 次，超出返回 429。
   - 默认按 TCP 对端 IP 限流；仅当应用位于受信反代之后时设置 `NOVEL_TRUST_PROXY=true`，才会读取 `X-Forwarded-For`（取最右一跳，防止伪造）。
6. **既有全书接口已加锁**：`/api/novel-full`、`/api/chapter-text/{n}` 现在需要登录，匿名者无法通过它们绕过试读。

> 开源版「**注册即全文**」，不设付费会员、不接支付。付费/订阅为商业版预留（`user_quotas.plan_type` 已具备扩展位），本期不启用。

## 接口一览

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/api/share/{id}` | 公开（限流） |
| GET | `/api/share/{id}/chapters` | 公开（限流） |
| GET | `/api/share/{id}/chapter/{n}` | 公开（限流），匿名超界 403 |
| POST | `/api/share` | 小说 owner / 管理员 |
| GET | `/api/shares/mine` | 已登录 |
| PATCH | `/api/share/{id}` | 该分享 owner / 管理员 |
| GET | `/api/bookshelf` | 已登录 |
