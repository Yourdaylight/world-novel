# 分享与注册阅读

## 权限模型

| 级别 | 身份 | 可访问内容 |
| --- | --- | --- |
| L0 匿名 | 未登录 | 封面 / 简介 / 目录 / **试读章节**（默认前 3 章） |
| L1 注册 | 已登录（jwt 邀请码 / casdoor） | **全书** + 书架 + 阅读进度 |
| L2 作者 | 分享创建者 | 全书 + 分享管理 |

开源版**注册即全文**，不设付费会员；付费会员为商业版预留。

## 作者：创建与管理分享

工作台 → 小说 → 侧栏「**分享阅读**」：

1. 点击「创建分享链接」，系统生成形如 `/read/9f3k2aBcXy12` 的公开地址；
2. 配置试读策略（即时生效）：
   - **前 N 章**（默认 3 章）
   - **按累计字数**（如 5000 字）
   - **按全书比例**（如 10%）
3. 复制链接发给读者；
4. 随时「关闭分享」——关闭后所有公开接口立即 404；
5. 查看浏览量 / 章节阅读量。

## 读者：试读 → 注册 → 读全书

1. 打开分享链接，看到书名、简介、目录；
2. 匿名可读试读章节，目录中超出试读范围的章节带 🔒；
3. 点击锁定章节 → 「立即注册 / 登录」→ 输入**邀请码**即完成注册登录；
4. 回到分享页即可阅读全书，进度自动保存，书架可查。

## 安全设计

- **后端是唯一真相**：目录接口只返回标题与「是否可读」标记，**绝不包含隐藏章节正文**；
- 匿名请求试读边界外章节 → `403 {code: "need_login"}`，响应体无正文；
- 分享 ID 为 12 位 URL 安全随机串（≈72 bit 熵），不可顺序枚举；
- 应用层限流：**单 IP 每分钟 ≤ 60 次**分享页/章节请求，超出返回 429；
- 关闭分享立即对所有人生效（无缓存）；
- 只有分享创建者（或管理员）能修改 / 关闭自己的分享。

## 部署：限流建议

应用内限流器是**单进程内存计数**，适用于 systemd + 单 uvicorn 进程的推荐部署。
若以 `uvicorn --workers N` 多进程或多机部署，请改用 nginx 限流：

```nginx
limit_req_zone $binary_remote_addr zone=share:10m rate=60r/m;

location /api/share/ {
    limit_req zone=share burst=20 nodelay;
    proxy_pass http://127.0.0.1:8000;
}
```

## API

```
# 公开面（限流，匿名可访问）
GET  /api/share/{id}              分享元数据 + 当前访问级别
GET  /api/share/{id}/chapters     目录（标题 + 可读标记，无正文）
GET  /api/share/{id}/chapter/{n}  章节正文（越界 403 need_login）

# 作者面（需登录）
POST /api/share                   创建/获取本书分享
GET  /api/share/mine              我的分享
PATCH /api/share/{id}             改试读策略 / 关闭（仅 owner）

# 读者面（需登录）
GET  /api/bookshelf               书架 + 进度
POST /api/bookshelf/progress      上报阅读进度
```

## 数据模型

- `share_links`：分享 ID、小说、owner、元数据快照、试读策略、状态、统计；
- `read_progress`：`(user_code, share_id)` 唯一的阅读进度（书架）。

> 设计说明：分享保存的是创建时的**元数据快照**（书名 / 简介），
> 因此后续修改原作不会影响已发出分享页的展示。
