# FAQ

## 通用

### WorldNovel 和 WorldEngine 是什么关系？

WorldEngine 是早期代号，现统一为 **WorldNovel**。代码包名仍保留 `novel_creator`。

### 可以不用 LLM 吗？

不可以。多 Agent 演化与写作都依赖 OpenAI 兼容的 LLM API。
支持 OpenAI、OpenRouter 及任意兼容网关（`NOVEL_OPENAI_BASE_URL`）。

## 认证

### jwt 和 casdoor 模式怎么选？

个人 / 开源部署用默认的 **jwt**（邀请码）模式；企业内需要统一身份认证（SSO）时用 **casdoor**。详见 [认证配置](./auth)。

### 忘记邀请码怎么办？

邀请码存于全局库 `data/novel.db` 的 `invite_codes` 表。
管理员可通过管理接口重新创建；以 `admin` 开头的邀请码自动获得管理员权限。

### disabled 模式安全吗？

disabled 模式下所有接口无需登录，**只适合本地开发或完全可信的内网**。
对公网提供分享阅读时请使用 jwt 或 casdoor 模式。

## 成书发布

### 为什么不能直接发布到番茄 / 七猫？

这些平台没有公开开放 API。WorldNovel 提供 L0 一键导出（平台规范格式），
上传动作需要作者在作家后台完成。详见 [成书发布](./publish)。

### 番茄导出为什么是 GB18030 而不是 UTF-8？

番茄作家后台对 TXT 导入的推荐编码是 GB18030，按平台规范导出可避免中文乱码。

### 质量门禁报「断章」但我确认章节都在？

门禁对比的是大纲计划章节数与 `chapter_texts` 中实际渲染的章节。
请检查是否有章节只完成了模拟、还没有「成文」。

### 敏感词预检能替代平台审核吗？

不能。内置词表只是基础辅助，最终以平台审核结果为准。
可在 `data/config/sensitive_words.txt` 维护自定义词表。

## 分享阅读

### 匿名读者能看到多少？

默认前 3 章，作者可在分享管理中按「前 N 章 / 累计字数 / 全书比例」调整，改完即时生效。

### 分享链接可以关掉吗？

可以。分享管理页「关闭分享」后，该链接的所有公开接口立即返回 404，随时可重新开启。

### 分享 ID 会被人遍历吗？

分享 ID 是 12 位 URL 安全随机串（约 72 bit 熵），且有单 IP 每分钟 60 次的限流，不可顺序枚举。

### 多进程部署限流还有效吗？

应用内限流是单进程内存计数。多 worker / 多机部署请改用 nginx `limit_req`，
见 [分享指南 → 部署限流建议](./share#部署-限流建议)。

## 部署

### 数据存在哪里？

- 全局库 `data/novel.db`：用户、邀请码、发布记录、分享、进度；
- 每本小说独立库 `data/novels/{id}/novel.db`：章节、大纲、记忆等；
- `data/registry.json`：书架元数据。

### 文档站必须和后端一起部署吗？

不需要。文档站是纯静态产物，详见 [独立部署文档站](./deploy-docs)。
