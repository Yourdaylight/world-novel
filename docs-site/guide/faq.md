# FAQ

## 通用

**Q：生成一部小说大概要多久 / 多少 token？**
A：取决于章节数与模型。10 章规模通常需要数十次 Agent 调用，可在「Token 统计」页实时查看消耗。

**Q：支持哪些模型？**
A：所有 OpenAI 兼容接口均可：OpenAI、OpenRouter、国内代理或自建网关。见[快速开始](./quickstart#3-配置-llm)。

**Q：数据存在哪里？**
A：全部本地 SQLite。每部小说一个库文件 `data/novels/{小说}/novel.db`，注册表在 `data/registry.json`，无外部数据库依赖。

## 发布

**Q：为什么不能直接一键发到番茄/七猫？**
A：这些平台没有公开开放 API，自动直发既不合规也不稳定。L0 导出严格按平台导入规范产出文件（GB18030 编码、分卷、字数建议），上传一步由作者完成。详见[成书发布](./publish)。

**Q：GB18030 编码是什么？为什么不用 UTF-8？**
A：番茄/七猫等中文平台的作家工具对 GB18030 TXT 兼容性最好；通用 TXT 与 EPUB 使用 UTF-8。

**Q：敏感词命中了怎么办？**
A：预检会列出命中词与所在章节，修改正文后重新预检即可。词表可用 `NOVEL_SENSITIVE_WORDS_PATH` 追加自定义词库。

## 分享与阅读

**Q：匿名用户能绕过试读限制吗？**
A：不能。正文只在服务端按权限逐章下发，抓包拿不到锁定章节；分享链接为随机短码不可遍历，并有限流。

**Q：必须接支付才能收费阅读吗？**
A：本期开源版无支付，注册即全文。付费会员字段（`plan_type`）已为商业版预留，接口不变即可扩展。

**Q：分享链接泄露了怎么办？**
A：分享管理页一键关闭，链接立即失效（所有接口返回 404）；之后可重新生成新链接（新随机码）。

**Q：casdoor 企业模式下读者怎么登录？**
A：阅读页自动识别认证模式，跳转企业统一登录；登录后同样全文可读。

## 部署

**Q：文档站能单独部署吗？**
A：可以，且推荐。`docs-site` 构建产物是纯静态目录，不含任何后端请求；停掉主服务文档照常访问。见[部署文档](./quickstart#deploy)。

**Q：JWT 默认密钥有风险吗？**
A：仅限本地开发。任何对外部署都必须设置 `WORLDENGINE_JWT_SECRET` 环境变量，详见[认证配置](./auth)。
