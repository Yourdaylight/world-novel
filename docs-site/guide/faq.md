# 常见问题

### 番茄 / 七猫能自动直发吗？
不能。这些平台没有公开作者 API。本期「一键发布」= 按平台规范一键导出成稿（番茄 GB18030、七猫分卷等），你在作家后台上传即可。浏览器半自动代填（L1）为预留能力。

### 匿名用户能通过别的接口拿到全书吗？
不能。全书/章节接口（`/api/novel-full`、`/api/chapter-text/{n}`）已要求登录；公开内容只能通过分享接口按试读边界获取，超出即 403 且不返回正文。

### 邀请码和注册是什么关系？
jwt 模式下邀请码就是注册/登录凭证：读者第一次用有效邀请码登录即完成注册，开源版「注册即全文」。管理员 code 以 `admin` 开头。

### 为什么公开分享页提示「请求过于频繁」？
公开接口默认 60 次/分钟/IP 限流，超出返回 429。如在反代之后，请正确设置 `NOVEL_TRUST_PROXY`，否则应用按 TCP 对端识别。

### disabled 模式下分享页为何能看全书？
disabled 模式视为「全部接口开放」的开发模式，所有访客都被当作已登录用户。**公网必须使用 jwt 或 casdoor 模式。**

### EPUB / Word 是怎么生成的，要装额外依赖吗？
不需要。EPUB 是符合 OCF 规范的 ZIP、Word 导出为 RTF，全部用 Python 标准库生成，无新增运行时依赖。

### 数据存在哪？
- 每部小说：`data/novels/<id>/novel.db`（章节、角色、时间线等 20+ 表）；
- 中央库 `data/novel.db`：邀请码、额度、`share_links`、`read_progress`、`publication_records`。
