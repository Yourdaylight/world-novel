# 成书一键发布

## 平台现实

番茄小说、七猫小说、起点、晋江等平台**均无公开开放的作者 API**。因此「一键发布」分层实现：

| 层级 | 能力 | 本期 |
|------|------|------|
| **L0 一键导出** | 按平台规范导出 TXT/EPUB/Word/全格式 ZIP，作者在平台后台上传 | ✅ 已实现 |
| L1 半自动 | Playwright 驱动作家后台、预填表单、停在「提交审核」前人确认 | 预留，未启用 |
| L2 全自动直发 | 仅当平台开放合规 API | 远期 |

## 使用流程

1. 小说生成完成后，进入工作台「**发布**」页；
2. 系统自动执行**发布前质量门禁**；
3. 选择目标平台，点击「一键导出」，浏览器下载成稿；
4. 登录对应平台作家后台上传，等待平台审核。

## 质量门禁（preflight）

`POST /api/publish/preflight` 检查：

- **阻断项（errors）**：无章节、章节断号（断章）、空章/过短章（<20 字）；存在阻断项时拒绝导出（422）。
- **提醒项（warnings）**：章节超过平台推荐字数（建议拆分）、低于推荐字数、缺少简介、**本地敏感词预检命中**。

内置基础敏感词表随包发布，可用 `NOVEL_SENSITIVE_WORDS_PATH` 指向自定义词表（每行一个词，`#` 注释）追加合并。平台侧仍会做正式内容审核，本地预检只是第一道。

## 导出格式

| 平台/格式 | 编码/结构 | 说明 |
|-----------|-----------|------|
| 番茄小说 | TXT · **GB18030** | 单卷、`第N章 标题`，番茄作家助手批量上传 |
| 七猫小说 | TXT · UTF-8 | **保留分卷**（`第N卷`），七猫作家平台导入 |
| 通用 TXT | UTF-8 | 任意平台 |
| EPUB | EPUB3（OCF zip） | Apple Books / 多看等 |
| Word | RTF | Word 直接打开，可另存 .docx |
| 全格式 ZIP | — | 一次打包以上全部 + 封面占位（SVG）+ 简介 + meta |

导出全部使用 Python 标准库生成（zipfile / 文本编码），**不引入新的运行时依赖、不新增常驻服务**，在 FastAPI 进程内完成，重 CPU 渲染会放到线程池避免阻塞事件循环。

## 发布记录

每次导出在中央库 `publication_records` 表留痕（平台、规格、字数、操作人、时间）。在平台侧完成发布后，可通过
`POST /api/publish/records/{id}/backfill` 回填平台书 ID / 链接，将状态标记为「已发布」。

## 部署注意

- L0 **零新增服务**；
- L1（未来）建议以独立 `publish-browser`（Playwright/Chromium）容器运行，仅暴露内部端口，浏览器崩溃不影响主服务；
- 限流建议在 nginx 层叠加 `limit_req`。
